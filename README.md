# Torix Health Florida

Marketing site for **Torix Solutions** — medical billing, coding, credentialing, and revenue cycle management.

Maintained by [Hammad Zubair](https://github.com/Hammad-Zubair-off).

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript
- Contact / hero lead forms via Resend or Gmail SMTP

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

See `.env.example` for email delivery options.
